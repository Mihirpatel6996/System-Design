# 🔐 Encapsulation: Access Levels in Python

In Python, access control is based on **conventions**, not strict enforcement like Java or C++.

👉 You *can* access everything — but you *shouldn’t*.

---

## 🟢 Public

```python
self.balance
```

### Meaning

* No restriction
* Can be accessed and modified from anywhere

### When to Use

* When the data is safe to expose
* No validation or protection needed
